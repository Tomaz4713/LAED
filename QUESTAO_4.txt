#LETRA C
#Rastreamento passo a passo:
#1. Push(5) -> Nó(5, min=5).                  Pilha: [5|5]                            -> Mínimo = 5
#2. Push(3) -> Nó(3, min=min(3,5)=3).         Pilha: [3|3] -> [5|5]                   -> Mínimo = 3
#3. Push(7) -> Nó(7, min=min(7,3)=3).         Pilha: [7|3] -> [3|3] -> [5|5]          -> Mínimo = 3
#4. Push(1) -> Nó(1, min=min(1,3)=1).         Pilha: [1|1] -> [7|3] -> [3|3] -> [5|5] -> Mínimo = 1
#5. Pop()   -> Remove o nó [1|1].             Pilha: [7|3] -> [3|3] -> [5|5]          -> Mínimo = 3
#6. Min()   -> Consulta topo.min_atual.       Pilha: [7|3] -> [3|3] -> [5|5]          -> Retorna 3
